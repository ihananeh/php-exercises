## PHP Message Decoder

Decode a confusing message using letter-based strings.


## About
Goal: Decode a mixed string of letters and numbers.
Process: Split the string, sort words by numeric part, and output only the letters.
Learning: Practice PHP arrays, regex, and string manipulation.



## How to Run
Save the PHP file (e.g., exercise.php).
 Run via CLI:
   ```bash
   php exercise.php
   ```
or open it in a browser on a local server.
You will see the letters printed in order based on the numeric part of each word.



## Example Input
  ```
  T4 l16 _36 510 _27 s26 _11 320...
  ```
## Example Output
  ```
  T _ m g h F t C z h n...
  ```
